# ♻️ Smart Bin & Clean City AI Platform

An AI-powered smart waste management and city cleanliness platform featuring real-time smart bin monitoring, incident tracking, AI-driven waste analytics, and interactive dashboards.

## 🚀 Features

- **Smart Bin Monitoring:** Track fill levels, locations, waste types, and critical alerts in real time.
- **AI-Powered Incident Detection:** Identify illegal dumping, public waste violations, and overflow warnings.
- **Product & Recycling Tracker:** Monitor recyclable products and user rewards points.
- **Interactive UI & 3D Visualization:** Modern dashboard interface with 3D city scene preview.

## 📁 Repository Structure

```
MiniProject/
├── Smart-Bin-Clean-City-AI-Frontend/   # React / Vite Frontend application
├── Smart-Bin-Clean-City-AI-Backend/    # Node.js / Express & AI Service Backend
├── run.bat                              # One-click Windows startup script
└── run_app.js                           # Integrated server runner
```

## 🛠️ How to Run Locally

### Option 1: One-Click Runner (Windows)
Double-click `run.bat` or run:
```bash
node run_app.js
```
Then open `http://localhost:5173` in your browser.

### Option 2: Run Frontend & Backend Separately

#### Frontend:
```bash
cd Smart-Bin-Clean-City-AI-Frontend/app
npm install
npm run dev
```

#### Backend:
```bash
cd Smart-Bin-Clean-City-AI-Backend/smart-bin-clean-city-ai-backend/backend
npm install
npm run dev
```
